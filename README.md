# For my Lovey

A monthsary surprise: make your character, then tap through a night-sky story — the shore, the pines, the little one on the way, and a wish.

Static site, no build step. Open `index.html` in a browser, or host the folder anywhere (GitHub Pages works: Settings → Pages → deploy from the `main` branch root).

- `index.html` — the page
- `gl.js` — GPU-rendered sky, sea and mountain backdrops (fallback when images are missing)
- `avatars.js` — pixel-art character creator and sprites
- `img/` — scene backdrops (sea, pines, baby)
